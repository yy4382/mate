# Mate

Persistent collaborative agents in Slack, powered by Pi Core.

Start with [development handoff](docs/HANDOFF.md), [technical design](docs/reference/slack-raft-pi-jev-technical-design.md), and the repository [Agent instructions](AGENTS.md).

Development follows sequential modules with an independent red-team review gate after each module. The developer will create `docs/IMPLEMENTATION_PLAN.md` and record reviews in `docs/reviews/`.

Local Raft prompt/log evidence under `docs/reference/raft-*.md` is private research material and intentionally excluded from Git.
