# 网页客户端边界测试

> 这个模块的设计见同目录的 [ARCHITECTURE.md](ARCHITECTURE.md)。所有模块共用的测试规则和替身见 [docs/MODULE_TESTS.md](../../docs/MODULE_TESTS.md)。

**边界：** HTTP 接口，加上浏览器里的页面行为。页面测试用浏览器测试工具（如 Playwright），驱动真实的前端和后端，后端的模型用脚本化提供商。


- 浏览器按本地语言偏好顺序显示简体中文或英文；覆盖区域语言、繁体中文归简体、不支持语言回退及忽略 URL / 存储覆盖。两种语言都从实际页面检查登录拒绝、导航、空状态、已知错误、变量和计数，用户内容和协议值不变。已有 classic 类型的通知 worker 能自动更新，新通知按本地语言显示，不要求重新订阅。

- 打开页面时选中的频道，在事件流建立之前就已确定：建立事件流时立即到达的消息不会丢失。
- 重放或重复的事件不会产生重复消息，也不会让讨论串的回复数虚增。
- 切换频道后，旧频道迟到的响应不会覆盖新频道的内容。
- 消息发送过程中又输入的文字，在发送成功后仍然保留。
- 发送请求的响应丢失后重试，不会产生重复消息（同一个请求 ID）。
- 收到"需要重新拉快照"后，页面重新加载状态，而不是停住。
- 会话过期时跳转到登录页，登录后回到原来的位置。
- 从推送通知点进来，直接定位到那条消息；消息不存在时，退回到最新消息，并显示提示。
- 手机宽度下可用。
- Node 页显示名字、在线状态和系统信息，旧 node 尚未报告时有明确提示。管理员可改名，重复名字的拒绝显示在名字字段下，非法输入不能提交，取消不改名字，刷新后保留结果。
- 创建 Agent 的 node 选择显示名字、提交 UUID，只有一个 node 时也显示名字。Agent 列表显示 node 名字，改名后列表和创建表单的缓存一起更新。
- 管理员在人类页添加一个普通人类；这个人在另一个浏览器里登录，能聊天，导航里没有"管理"，直接打开管理地址看到"需要管理员权限"。
- 退出登录（个人资料页或导航菜单）先取消这个浏览器的推送订阅，再结束登录会话，所以同一个浏览器上下一个登录的人类不会收到上一个人类的通知；取消订阅失败时仍然退出。测试用往页面注入的脚本假装浏览器已订阅，检查发出的取消订阅请求和随后的登录页。
- 人类在个人资料页改显示名和 handle：导航立即显示新名字，用新 handle 能再登录；改成被占用的 handle，在 Handle 字段下显示"已被占用"。
- 改密码时当前密码不对、新密码太短都在字段下显示；改对之后当前登录继续有效，新密码能登录。
- 最后一个管理员被降级时页面显示"必须至少保留一个有效的管理员"；停用先弹确认，取消什么都不变，确认后那一行显示"已停用"。
- 人类页上自己那一行的"更多"菜单里有"编辑个人资料"，点了进入个人资料页；别人的行没有这一项。

**实现。** `apps/web/test/*.test.ts` 在 vitest 里把 Playwright 当库用（无头 Chromium）。每个 worker 用 Vite 的 `build()` 把前端构建一次到临时目录，作为 `webDirectory` 交给进程内启动的真实控制面（可控时钟，Agent 用假 node 和脚本化提供商）。浏览器走 `localhost`，因为 `__Host-` 的 Secure cookie 只在安全上下文里保留。拿不到的网络行为用 Playwright 的路由截获（挂起一个响应、丢掉一个响应、让事件流发 `resnapshot`），重放事件用往页面注入一个让每批事件重复投递的脚本。聊天（会话、未读、讨论串、任务、搜索、历史翻页）、管理（提供商、node 配对、创建 Agent 与私信、观察、工作区、设置、暂停恢复删除）和人类（添加、个人资料、改密码、最后一个管理员、停用）各一个文件。Web Push 的订阅和系统通知依赖浏览器的推送服务，无头环境里没有，不在这里测（退出登录时的取消订阅除外：页面里注入一个假的订阅，只看发给控制面的请求）；通知点开后的定位用同一个地址测。

**头像浏览器场景**（`apps/web/test/avatars.test.ts`）：通过真实文件输入上传与替换，观察个人资料、导航、人类管理、Agent 列表与详情、消息作者、搜索、私信列表和私信标题。另一个已打开的页面实时更新，刷新后图片仍在。管理员更换其他人类头像，普通人类只改自己的。JPEG 和 WebP 经浏览器裁剪缩放，服务端转为 WebP 后实际显示为正方形；无效文件与超过 5 MiB 的文件就地报错。上传图加载失败回落默认，更换后恢复加载。两个页面先后更换同一账号头像时，较早上传的响应迟到不会让已显示的新头像退回旧图。外观截图夹具同时包含上传头像和默认头像，覆盖桌面、暗色、手机。
- Agent 设置页的 Webhook 区：创建时密钥只在对话框里出现一次，关闭后列表里没有它；用这个密钥投递返回 202；轮换后旧密钥 401、新密钥 202；删除后 401，列表回到空状态。
