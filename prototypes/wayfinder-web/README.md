# Mate 网页信息架构抛弃式原型

问题：聊天、任务、Agent 和节点如何在桌面与手机上组织？原型有三种结构布局，通过底部切换条或左右方向键切换，URL 的 `?variant=A/B/C` 可以直接分享。所有内容是合成示例，操作只在浏览器内存中生效。

在仓库根目录运行：

```sh
python3 -m http.server 8760 --directory prototypes/wayfinder-web
```

然后打开 <http://localhost:8760/?variant=A>。把浏览器缩窄到手机宽度可比较移动布局。

- **A 常驻三栏**：窄图标栏、二级列表、主内容；消息下方预览讨论串的回复数与最近三条摘要，点击后在桌面右侧或手机全屏打开完整讨论串。
- **B 专注页面**：顶部全局导航、左侧列表；thread 占据主内容并通过返回进入原频道。
- **C 工作标签**：窄图标栏、二级列表、主区标签；右侧常驻待处理收件箱，thread 在标签中。

消息上的“回复”会在当前频道或私信发送一条带原消息引用的新消息；“开启讨论串并回复”或“在讨论串回复”会进入该消息的讨论串，回复留在讨论串内，并更新主聊天中的预览。

桌面端将鼠标移到消息上会显示操作栏；手机端点击消息右上角的“⋯”打开同样的操作。讨论串预览始终可见。

此目录不属于产品实现。决策确认后，将结论写入决策票并在后续 spec 中重新实现。
