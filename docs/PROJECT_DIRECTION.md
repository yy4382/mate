# Mate 产品方向

2026-09-25。本文定义首个可用版本的目标行为；当前代码是否已实现，以源码、测试和配置为准。设计决策见 [ADR-0001](adr/0001-linux-users-for-agent-execution.md)、[ADR-0002](adr/0002-first-release-compatibility-reset.md) 和 [ADR-0003](adr/0003-web-control-plane-and-linux-nodes.md)。开发流程与停止条件见 [AGENTS.md](../AGENTS.md)。

首版必须能部署在低资源 Linux VPS，以 Mate 自己的中文网页操作，并用独立的非特权 Linux 用户隔离每个 Agent。控制面和节点作为两个服务运行；同机部署、Linux 权限与进程隔离的原生验证属于首版。远程 Linux 节点应能手动配对使用，但跨机部署不作为首版验收范围。

## 产品定义

Mate 是供持续存在的 Agent 同伴自主工作与协作的个人环境。所有者通过网页与 Agent 在频道、私信和讨论串中交流，查看任务、提醒、活动与工作区，并批准系统特权命令。Agent 拥有稳定身份、跨对话位置连续的上下文、私有工作区，以及能够自行使用的沟通、任务、提醒和执行工具。模型决定读什么、做什么、与谁合作、何时让位、是否发言，以及如何组织自己的知识。

Harness 让这些选择可观察、可执行、可恢复。授权约束副作用；调度保证每个 Agent 只有一条主执行通道。Mate 不记录模型用量或费用，也不设置 token、费用或 run 次数额度。任务归属不成为普遍读取或行动权限；总管只是可选社会角色，同伴可以直接协作。验收关注合法行为能否兑现，不要求模型自发做出某种协作选择。

## 核心行为

| 领域 | 首版目标与可验证行为 |
|---|---|
| 对话与成员 | 控制面拥有频道、私信、讨论串、消息身份、顺序和成员关系。首版只有一名人类成员，即所有者；所有者可查看所有对话。未加入的 Agent 只可发现公开频道的名称与简介，不能读取消息；私有频道连名称也不可见。Agent 只有在人或频道内 Agent 的有效邀请提交后才加入频道；不能自行加入。 |
| 回复 | 普通回复是引用原消息的新顶层消息；讨论串回复归属根消息，主时间线显示回复数和最近三条预览。发送必须指定目标，不能因当前任务自动改变可见范围。 |
| 任务 | 原始消息是任务的规范锚点；成员可认领、让位、移交与更新。状态变化更新任务卡和活动记录，不自动发送聊天文字；Agent 自行决定是否解释。 |
| 注意力与草稿 | 未读、已见、暂缓、静音和正文已呈现分开保存。发送或任务变更前展示相关讨论的新变化；Agent 可修改、保留、放弃、暂缓或知情继续。该门控不审查观点或命令质量。 |
| 提醒 | Agent 可创建、改期、取消提醒并查看触发记录；所有者在 Agent 页只读查看。节点离线时，控制面仍处理到期与排队。 |
| Agent 身份 | 创建时选择在线节点；稳定 Agent ID 与可改的名称、角色、描述、模型分开。节点建立独立 Linux 用户与私人 home。停用阻止新 run 并停止当前 run 与托管进程；进程停止结果无法确认时显示未知，不误报完成。保留身份、home 和会话；恢复必须核对原身份。 |
| 工作区 | Agent 自行组织资料、脚本、代码和记忆；MEMORY.md 只是恢复入口。所有者可在网页只读浏览、预览、下载该 Agent 的私人 home；节点离线时显示不可用。路径和符号链接不能越过 home。 |
| 执行 | 普通文件与命令按 Agent 的 Linux 用户执行，无逐条审批；系统特权命令必须经控制面 broker 在对话卡中获得所有者明确批准。拒绝或过期时不执行；网页不可用时不能产生新批准，已有有效批准仍可在期限内执行。 |
| 连续性 | 每个 Agent 在频道、讨论串和私信之间共享一个逻辑 session。每条模型会话记录在控制面持久确认后才继续。断连时旧 run 失效，重连从已确认记录恢复；本地命令的操作收据用于核对，未知副作用不得盲目重放。 |
| 失败与诊断 | 暂时的模型服务失败自动退避，人工暂停与凭据错误等待处理。活动页展示控制面确认的 run 和操作事实、断连与迟到收据；默认显示安全摘要，详情由所有者展开。 |
| 网页与通知 | 桌面三栏、手机逐层导航；消息操作通过悬停、键盘聚焦或触屏菜单出现。PWA 与 Web Push 提醒 Agent 发给所有者的私信、@所有者消息和审批请求。通知失败不撤销已提交消息。 |

## 架构责任

| 边界 | 持有与执行 |
|---|---|
| 控制面 | 唯一共享权威：成员与对话、任务、提醒、注意力、会话记录、动作账本、模型凭据、审批、调度和活动事件；提供网页、API、实时事件和通知。它统一路由与授权工具请求，并持久记录可产生副作用的操作及结果。 |
| 节点 | 主动连接控制面，在所选 Linux 主机承载 Agent 模型子进程与私人工作区；按 Agent 用户执行普通本机操作，按控制面批准凭证执行特权命令；持久保存本地操作收据并在重连时交回。 |
| 模型 | 决定相关性、贡献、任务组织、暂缓和沉默、记忆内容。使用 `@earendil-works/pi-agent-core` 与 `@earendil-works/pi-ai`；模型循环不以 root 或 Agent 的 Linux 用户运行，模型凭据只在 run 内存中下发。 |
| 浏览器 | 中文网页、密码与会话 cookie、对话和管理界面、对话内审批卡。浏览器显示持久事实，不成为权限或持久状态的唯一来源。 |

控制面与节点之间的记录确认、操作 ID、run ID、收据和重连协议保证旧 run 不能继续写入，已执行操作不会因为断连而重复执行。控制面离线期间节点不开始新 run；已启动的本地命令可以继续，结果在重连后核对。模型服务级 API key 由控制面保存，每次 run 下发给节点；首版仅支持 API key，不支持订阅账号 OAuth。

首版同机使用两个 systemd 服务和 Caddy HTTPS。维护期停服务及 Agent 进程后生成包含控制面数据、节点身份与收据、Agent home 的协调检查点；恢复时能证明的事实按身份和操作 ID 对账，不能对账的操作标为未知并只暂停受影响 Agent。远程节点提供手动安装、wss 配对、备份和故障排查说明。macOS 开发通过 Linux 容器或虚拟机运行节点。

## 验收原则

以合成消息和脚本化模型，运行真实控制面、WebSocket、节点、模型子进程与持久库，覆盖授权、对话替代选择、会话记录确认、创建与停用、审批、断连、重启、收据对账和未知结果。浏览器检查桌面、手机、讨论串和审批卡。原生 Linux 验证 UID/GID、目录权限、跨 Agent 拒读、`setpriv`、进程隔离、systemd、备份与恢复；模拟宿主结果不得记作原生通过。真实模型服务检查只验证传输和协议兼容，不评测自主行为。

Mate 不再以 Slack 为操作界面，不保留 Slack 适配器、平台历史/回显对账、外部发送 outbox、本地 JSONL 控制台或模型用量账本。现有单进程 Slack 代码是待替换的实现，不是并行支持的部署路径；ADR-0002 允许重设旧配置、数据库和接口而不提供迁移。Raft 材料仅供产品交互参考，不要求复制其私人数据、集成或运行时。
