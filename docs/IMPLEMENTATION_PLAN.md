# First usable release

The release target is a Debian 13 VPS application operated through Slack. Each Agent runs ordinary commands under its own unprivileged Linux user, with private memory and notes, a shared work area, familiar host files and network access, and long-running processes. Mate's control data stays outside Agent access. Every system-privileged command waits for explicit user approval in the UI. See [project direction](PROJECT_DIRECTION.md), [decision](adr/0001-linux-users-for-agent-execution.md), and [deployment](DEPLOYMENT.md).

GitHub Issues is the live spec and ticket tracker; use the issue's acceptance criteria and blocking edges rather than a second backlog in this file. The implementation is in transition: passing earlier local tests does not establish this release target. In particular, remove superseded execution/deployment paths instead of maintaining compatibility. Work through feasible tickets and focused checks before stopping for Slack/provider connection or actual VPS deployment.
