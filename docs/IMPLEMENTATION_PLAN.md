# First usable release

The first release runs on a Debian 13 VPS and is operated through Slack. Each Agent has its own Linux user account and uses that account to read ordinary files, run commands, and keep long-running programs alive. Only that Agent can read its private memory and notes; colleagues can read work placed in the shared directory. Agents can use the host's tools and network, but cannot read Mate's database or credentials. A system-level command runs only after the human user approves that request in Slack. See [project direction](PROJECT_DIRECTION.md), [decision](adr/0001-linux-users-for-agent-execution.md), and [deployment](DEPLOYMENT.md).

GitHub Issues holds the current requirements and work items. Each work item says what it delivers, which earlier work must finish first, and how to check the result. Local tests alone do not prove that Mate works with real Slack, a real model provider, or on the target VPS; those connections and the actual installation are the final checks.
