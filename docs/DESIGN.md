# Mate 界面规范

> 读者：要改 `apps/web` 的工程师或 Agent。改界面之前读一遍。

界面走 Vercel（Geist）那一路：中性的黑白灰，细边框，留白充足，强调色只有一个蓝色，主要按钮用前景色（浅色模式下是黑）。不追求特色，追求一致。

## 1. 技术选择

- **样式：Tailwind CSS v4。** 只写工具类，不写新的 CSS 规则。`src/shell/theme.css` 是唯一的样式文件，里面只有设计变量（`@theme`）、暗色模式的变量覆盖和极少的全局基础样式。
- **交互组件：Base UI（`@base-ui/react`）。** 对话框、确认框、菜单、标签页、提示用它，不自己写焦点管理、键盘操作和弹层定位。
- **图标：lucide-react。** 界面上不出现 emoji。只有图标没有文字的按钮必须带 `aria-label`。
- **字体：Geist 和 Geist Mono**（`@fontsource-variable`），中文回落到系统字体（PingFang SC、Noto Sans SC、微软雅黑）。
- **原语集中在 `src/shell/ui.tsx`。** 按钮、输入框、卡片、徽章、对话框、菜单、标签页等都从这里引入。页面里不直接拼按钮或输入框的样式，需要新变体就加到原语里。
- **类名用 `cx` 拼。** 它经过 tailwind-merge，所以传给原语的 `className` 一定覆盖原语自己的同类样式（颜色、高度、内边距），不需要 `!important`。
- 下拉选择用原生 `<select>`，套统一样式。手机上弹出系统自带的选择器，比自绘的好用。

## 2. 设计变量

颜色只从变量里取。页面代码里不出现十六进制颜色，也不直接用 `gray-500` 这类 Tailwind 色板。

| 变量（Tailwind 类名） | 用途 |
|---|---|
| `background` | 页面底色 |
| `subtle` | 侧栏、表头、悬停行、代码块的底色 |
| `foreground` | 正文、主要按钮的底色 |
| `muted` | 次要文字：时间、说明、占位 |
| `backdrop` | 对话框背后的遮罩 |
| `border` | 所有分隔线和边框 |
| `border-strong` | 输入框、悬停时的边框 |
| `accent` | 链接、@提及、焦点环、未读提及 |
| `success` / `warning` / `danger` | 状态点、状态徽章、危险操作 |

暗色模式跟随系统（`prefers-color-scheme`），只靠覆盖这些变量实现，组件里不写 `dark:`。

## 3. 间距和尺寸

用 Tailwind 的 4px 刻度，只用下面这几档，不临时发明数字。

- **控件高度统一 `h-9`（36px）**：按钮、输入框、选择框同高，放在一行里能对齐。小号 `h-8` 只用在消息、任务这类行内操作。手机上的底部导航条目 `h-14`。
- **页面边距**：内容区 `px-4`（手机）/ `px-8`（桌面），顶部 `py-6` / `py-8`。管理类页面内容最大宽度 `max-w-4xl`，居中。
- **纵向节奏**：页面标题和下面内容之间 `gap-6`；区块之间 `gap-8`；表单字段之间 `gap-4`；标签和控件之间 `gap-1.5`；卡片内边距 `p-4`（紧凑行）或 `p-5`（表单）；对话框和登录卡片这类独占一屏的卡片用 `p-6`。
- **圆角**：控件 `rounded-md`，卡片和菜单 `rounded-lg`，对话框 `rounded-xl`，头像和状态点 `rounded-full`。
- **字号**：界面默认 `text-sm`（14px）；次要信息 `text-xs`（12px）+ `muted`；页面标题 `text-2xl font-semibold tracking-tight`；区块标题 `text-base font-semibold`。正文消息 `text-sm leading-6`。

## 4. 布局

- **桌面**：左边一条 240px 的侧栏，右边是内容。侧栏从上到下是：品牌行、主导航（聊天、管理）、当前功能区的二级导航（聊天时是会话列表，管理时是 Agent / 提供商 / Node / 人类）、底部账号菜单（触发器是当前人类的头像和显示名；菜单里是通知开关、个人资料、退出）。普通人类看不到"管理"和它的二级导航；直接打开管理地址时页面显示"需要管理员权限"，不请求任何管理数据。
- **手机（< 768px）**：没有侧栏。底部固定一条主导航（聊天、管理（管理员才有）、账号菜单），会话列表和打开的会话各占一整屏，打开的会话左上角有返回。
- 打开讨论串时，讨论串作为右侧面板出现（桌面），手机上占满整屏。

## 5. 交互规则

- **一个区域最多一个主要按钮**（黑底），其余用次要按钮（白底细边）或幽灵按钮（无边框）。
- **危险操作不外露。** 删除、归档、离开放进"更多"菜单，点了弹确认框（Base UI AlertDialog），确认按钮用红色并写明动作（"删除 Agent"）。不可撤销的操作永远不能一次点击完成。
- **行内操作悬停才出现。** 消息上的"回复""转为任务"在桌面上鼠标悬停或键盘聚焦到这条消息时出现在右上角；没有悬停能力的设备（`@media (hover: none)`）上一直显示。
- **创建类表单用对话框**（新建会话、创建 Agent、配对 node、添加人类），不把表单插进列表里。
- **表单卡片**：字段在卡片里，卡片底部一条 `subtle` 底色的操作栏，左边放说明或危险操作，右边放主要按钮。
- **表单里的拒绝贴着出错的字段。** 能对应到一个字段的拒绝（handle 被占用、当前密码不对、新密码太短）写在那个字段下面（`Field` 的 `error`），对应不到的写在表单底栏。客户端能判断的（太短、两次不一致）不发请求。
- **反馈就地出现**：保存成功、出错的提示放在触发它的按钮旁或表单底栏，不弹全局通知。
- **空状态**要说明这里会出现什么、下一步做什么，并给出那个操作的按钮。
- **头像**：Agent 用 DiceBear thumbs，按聊天账号 ID 生成（`Avatar` 的 `agentAccount`，URL 只在 `ui.tsx` 里拼，主版本固定 `10.x`）。浏览器直接引用，靠 DiceBear 的一年缓存头，服务器不存也不转发。人类显示名字的首字母。人类列表里当前这个人的行带"你"徽章，它的"更多"菜单第一项是"编辑个人资料"，通往个人资料页。图片加载失败回落首字母。
- 焦点环统一 `accent` 色 2px，键盘可以走完所有操作。

## 6. 检查外观

改完界面后截图看一遍，桌面、暗色和手机三种视图都要看：

```sh
MATE_SCREENS=/tmp/mate-screens pnpm vitest run apps/web/test/screens.test.ts
```

它起一个带示例数据的控制面，把每个页面截成 PNG 放进那个目录。不设 `MATE_SCREENS` 时这个文件跳过，不影响 `pnpm test`。

## 7. 原生移动客户端

通知设置页使用同一套原生颜色与 48pt 控件。系统权限、服务器配置和成功登记使用不同文案；未配置 APNs 或没有签名不能显示已开启。拒绝权限时提供 iOS 设置入口。关闭、退出或换服务器失败时说明远端取消未确认，不把本机关闭等同于远端撤销。通知只显示通用私信或提及提示，不带消息正文。

`apps/mobile` 沿用中性黑白灰、细边框、4px 间距刻度和中文术语，浅色与暗色跟随系统。原生界面使用 React Native 的样式和系统字体，导航由 Expo Router 提供，安全区由 `react-native-safe-area-context` 处理；网页的 Tailwind、Base UI 和 DOM 原语仍留在 `apps/web`。

登录后进入聊天 Tab。管理员有聊天、Agent、设置三个系统原生 Tab，普通人类有聊天和设置。每个 Tab 保留自己的原生 Stack 与返回位置。设置承接个人资料、通知、账号与连接；管理 Mate 只列提供商、Node 和人类。旧 URL 保留，角色继续来自服务器。Agent 详情可打开对应私信，保持正常的原生返回路径。地址只接受 HTTPS origin，换地址后重新登录。错误就地显示，401 与连接失败使用不同文案；离线退出明确提示服务器撤销未确认。输入框支持系统密码填充和键盘的下一项、登录操作，表单随键盘避让并可滚动；文字跟随 Dynamic Type，按钮和输入框最小高度为 48pt，不限制放大倍数。后续功能可以按设备设计布局，不要求照搬网页。不做 iPhone Duo 专用布局或折叠状态处理。检查原生界面时，在可用的 iOS 27 或更新版本的模拟器、真机上查看浅色、暗色和放大字体；网页截图命令不覆盖原生界面。

原生聊天的消息使用虚拟列表，讨论串单独占一屏，成员与消息任务操作使用系统 sheet。离开和归档在「更多」内二次确认。输入框保留每条时间线的草稿，发送失败就地提供同一请求的重试。Markdown 使用原生文本渲染库，跟随主题和 Dynamic Type，支持文本选择、代码块和表格；Markdown 复选框只读，消息任务仍由 Mate 的任务操作处理。导航栏操作使用系统工具栏按钮，输入区可独立滚动，最大辅助字体下也能到达发送操作；键盘避让读取实际导航栏高度。

共享原生展示集中在 `apps/mobile/src/ui.tsx`，`admin/ui.tsx` 只保留管理错误格式与结果展示并转出共享组件。`Section`、`Row`、`Field`、`Sheet` 统一分组面、细分隔线、系统字体和可滚动表单。`theme.ts` 定义明暗语义色与正文、标题、元信息字号。页面不建立新的业务状态 owner。受保护原生 sheet 根据访问权限和当前页面焦点隐藏，保留挂载的草稿与搜索。

Tab Bar 仅在聊天、Agent 和设置根页显示，详情使用完整原生 Stack，避免覆盖固定消息输入栏。Agent 的原生 Tab 使用 `/agents`；旧 `/admin/agents` 路径保留有角色保护的兼容入口。导航大标题不设置不透明 header 背景，交给 iOS 绘制材质。

会话的消息菜单、成员、任务与原帖共用一个原生 pageSheet。短表单输入、邀请搜索和任务转交选择由 modal 外的页面持有，认证暂停隐藏原生 presentation 后仍能恢复。任务行直接显示无人认领、负责人或已完成，不用空完成圆圈暗示立即完成。只有已知有回复的消息显示讨论串文本入口，其余消息通过显式菜单回复。
