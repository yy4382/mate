# 历史操作结果未知时默认继续工作

原 Agent 身份、同一会话和执行环境仍可使用时，恢复流程不能为了证明历史操作结果而永久暂停整个 Agent；Mate 默认保留未知事实，将其持久提供给 Agent，并自动允许后续工作，无需所有者复核或确认。保持工作能够继续优先于补齐历史结果，Agent 自行决定检查、补救或继续；运行时不把未知改判为成功或未执行，也不自动重放已执行或结果未知的操作。

这一选择不解除所有者主动设置的暂停，不创建第二条会话，也不恢复已结束 run 的提交资格；历史命令是否已经停止仍如实记录，不能由 Agent 已继续运行推断。维护恢复仍通过停服、核对、启动的既有入口执行；历史证据不完整不再构成整个 Agent 的运行前提，实际不可用的身份、会话或环境则报告阻因并提供修复后重新核验的出口。

行为与验收见[规格 #115](https://github.com/yy4382/mate/issues/115)，替代尚未实现的人工复核放行方案 #104。
