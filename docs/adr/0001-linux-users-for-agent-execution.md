# Use Linux user identities for ordinary Agent execution

Mate's first Linux VPS release runs each Agent's ordinary commands as its own unprivileged Linux user, rather than making Docker/gVisor the default execution layer. Separate Unix identities and private directory permissions address the primary cross-Agent knowledge boundary while preserving the normal host filesystem and toolchain; controlled per-command process units and resource limits remain Mate's responsibility. A separate review identity cannot inherit the reviewed Agent's private access.

This replaces the earlier Docker/gVisor default selected during F1 research. The container approach added images, path/mount parity, networking, grant-generation, and container lifecycle machinery, while an Agent that could independently choose ordinary host execution could bypass much of that machinery. Ordinary Agent execution still must not inherit Mate's control-plane identity, root, Docker control, or other Agent private access. System-privileged execution is exceptional: each command request requires the human user's explicit UI approval before it runs, and an absent, rejected, expired, or mismatched approval does not authorize execution. Approval identifies the requested operation; it does not freeze every script or dependency that operation may load, so the UI must not imply otherwise.

Consequences: each Agent keeps a stable private and shared workspace across commands and restarts; ordinary work does not lease per-command filesystem access or rotate mount/grant generations. Mate must validate Unix ownership/ACLs, keep control-plane secrets and local sockets outside Agent access, and account for and stop Agent-owned background processes. Changing or disabling an Agent's OS access is an explicit administrative maintenance operation, not an automatic grant-expiry workflow. These are focused Debian 13 acceptance checks, not a new broad sandbox-backend benchmark. The older container implementation and native research remain historical evidence, not proof that the new boundary has been delivered.
