# 原生运行时自动压缩上下文

具体压缩实现已由 [ADR-0010](0010-durable-agent-runtime.md) 替代：直接采用 Durable 的容量触发、近期交互保留、overflow 处理和摘要提交；不维护移植 Pi 0.86 的算法、提示或旧压缩记录。首轮关闭后台预压缩，使用原生阻塞压缩。

保留长期工作的产品原则：摘要提交成功后才使用新上下文，失败或中断不切换未提交摘要；同一 Agent session 继续，压缩前的完整已确认历史仍可搜索和读取，工具调用与结果关联有效。容量是上下文约束，token 和缓存统计只是观察，不构成用量额度。普通及摘要统计从同一提交范围和 provider/model 分组的原生事实投影，缺失值保持未知。
