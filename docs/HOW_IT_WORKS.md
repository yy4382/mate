# Current implementation status

Mate uses Pi Core and pi-ai to run Agents, SQLite to save their conversation state and action results, and Slack or a local console for human interaction. Agents have tools for messages, tasks, reminders, files, and commands. The source and tests show what works today; [project direction](PROJECT_DIRECTION.md) defines the goal, and [acceptance](ACCEPTANCE.md) lists the release checks.

The current Linux path runs each Agent's ordinary file and command operations under its configured Linux account. Mate keeps the same home and shared paths across commands and restarts, and ordinary Unix permissions protect private files and Mate's control data. System-level commands enter a pending state and run only after the user approves the individual request in Slack; rejection, expiry, or an unavailable approval message prevents execution. Local integration tests cover this path, and a small Debian 13 check covers native user permissions and process stopping. The installed Mate build on the target VPS and real Slack/provider connections have not yet been verified; see [acceptance](ACCEPTANCE.md).
